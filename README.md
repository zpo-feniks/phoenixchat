# ФениксЧат v1.0 — мессенджер без сервера

Прямой обмен **текстовыми, голосовыми и видео-сообщениями**, фото и файлами между устройствами. Устройства соединяются напрямую (P2P, WebRTC), канал шифруется (DTLS), история хранится только на ваших устройствах. Промежуточного сервера нет.

## Что внутри пакета

| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `js/` | Само приложение |
| `manifest.json`, `sw.js`, `icons/` | Установка как приложение (PWA) и офлайн-режим |
| `serve.ps1`, `start-windows.bat` | Локальный сервер для Windows (ничего устанавливать не нужно) |
| `README.md` | Эта инструкция |

## Возможности

- 💬 Текстовые сообщения, статусы доставки (✓ отправлено / ✓✓ прочитано)
- 🎙 Голосовые сообщения (до 2 минут)
- 🎬 Видеосообщения с камеры (до 60 секунд)
- 📎 Фото, изображения и любые файлы (передача кусками по 16 КБ)
- 🔒 Шифрование канала WebRTC DTLS — ключи не покидают устройства
- 📴 Офлайн: история хранится локально (IndexedDB), интерфейс работает без сети
- 🖥 Режим «На этом устройстве»: два окна одного браузера соединяются без кодов

## Честные ограничения

- **Нет push-уведомлений**: без сервера сообщение доставляется, только когда оба устройства онлайн одновременно. Договоритесь о времени созвона заранее.
- Сопряжение новых устройств — разовый обмен кодами (как в Briar/Tox).
- Без TURN-сервера: если оба устройства находятся за «строгими» NAT в разных сетях, прямое соединение может не установиться (в одной Wi-Fi-сети и в большинстве домашних сетей работает).
- Файла установки `.ipa` для iPhone в этом пакете **нет и быть не может**: Apple запрещает собирать приложения для iOS где-либо, кроме Mac с Xcode. Для iPhone приложение устанавливается как веб-приложение через Safari (раздел ниже).

## Установка на Windows

1. Распакуйте папку в удобное место (например, `C:\PhoenixChat`).
2. Дважды щёлкните **`start-windows.bat`** — откроется браузер с приложением (`http://localhost:8000`).
3. Чтобы установить как обычную программу: в Chrome/Edge откройте меню **⋮ / …** → **«Приложения»** → **«Установить сайт как приложение»** (или кнопка «⬇ Установить» в левом нижнем углу ФениксЧата). Появится отдельное окно с иконкой в меню «Пуск».

Примечания:
- Окно `start-windows.bat` должно оставаться открытым, пока вы пользуетесь приложением (это ваш локальный сервер).
- Чтобы ФениксЧат запускался при старте Windows: нажмите `Win+R` → `shell:startup` → скопируйте туда ярлык `start-windows.bat`.
- По локальной сети (`http://IP-компьютера:8000`) телефоны смогут писать текстом, но микрофон/камера работать не будут — браузеры разрешают их только по HTTPS. Для полного функционала на телефонах используйте хостинг (ниже).

## Установка на Android

### Вариант А — веб-приложение (рекомендуется, 5 минут)

Приложение нужно один раз выложить на бесплатный HTTPS-хостинг, тогда на телефоне оно устанавливается с иконкой и работает офлайн.

**Шаг 1. Хостинг на GitHub Pages (бесплатно):**
1. Заведите аккаунт на [github.com](https://github.com) (если нет).
2. Нажмите **New repository** → имя, например `phoenixchat` → **Public** → **Create**.
3. **Add file → Upload files** → перетащите **содержимое** этой папки (index.html, style.css, manifest.json, sw.js, js/, icons/, serve.ps1, start-windows.bat, README.md) → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ_ЛОГИН.github.io/phoenixchat/`.

*Альтернативы без GitHub:* Netlify Drop (app.netlify.com/drop — перетащить папку), Cloudflare Pages, Vercel.

**Шаг 2. Установка на телефон:**
1. Откройте эту ссылку в **Chrome** на Android.
2. Меню **⋮** → **«Добавить на главный экран»** → **Установить**.
3. На главном экране появится иконка ФениксЧата; приложение запускается в отдельном окне, работает офлайн.

### Вариант Б — настоящий APK-файл установки

Из HTTPS-ссылки (после шага 1 выше) можно собрать подписанный APK — тогда приложение устанавливается как обычное Android-приложение, без Chrome:

1. Откройте [pwabuilder.com](https://www.pwabuilder.com) (бесплатный инструмент Microsoft).
2. Вставьте адрес `https://ВАШ_ЛОГИН.github.io/phoenixchat/` → **Start**.
3. **Package for stores** → **Android** → **Download** — получите ZIP с файлом `app-release-signed.apk`.
4. Перекиньте APK на телефон (по почте, кабелем, через диск), откройте его → разрешите «Установку из неизвестных источников» → Готово.

Для публикации в Google Play нужен аккаунт разработчика ($25, разово) — но для личного пользования APK хватает.

## Установка на iPhone / iPad

1. Выложите приложение на HTTPS-хостинг (шаг 1 из раздела Android — он общий).
2. Откройте ссылку в **Safari**.
3. Кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **Добавить**.
4. Иконка появится на рабочем столе; приложение открывается на весь экран, без адресной строки, работает офлайн.

Это единственный законный способ установки на iOS без Mac и аккаунта разработчика Apple ($99/год). Файл `.ipa`, собранный вне Xcode, на iPhone всё равно не установится.

## Как соединить два устройства

1. На первом устройстве: **«Новая беседа» → «Создать приглашение» → «Создать код приглашения»**. Появится код `FCHAT-O-…`.
2. Передайте его собеседнику (любой мессенджер, почта, показать экран — канал всё равно шифруется).
3. На втором устройстве: **«Новая беседа» → «Принять приглашение»** → вставить код → **«Создать ответный код»**.
4. Ответный код `FCHAT-A-…` передайте обратно и вставьте на первом устройстве → **«Подключить»**.
5. Соединение установлено — можно переписываться. Повторное сопряжение не требуется, пока соединение живо.

Удобнее передавать не код, а **ссылку-приглашение** (кнопка «Скопировать ссылку-приглашение»): собеседник открывает её, и код подставляется автоматически.

Если оба окна на одном компьютере — вкладка **«На этом устройстве»** соединяет их без кодов.

## Приватность

- Сообщения идут напрямую между устройствами (WebRTC DataChannel), шифрование DTLS; серверов ФениксЧат не имеет в принципе — перехватить посередке нечего.
- История сообщений хранится только локально на каждом устройстве.
- Публичный STUN-сервер Google используется только чтобы устройства могли «найти» друг друга в интернете — содержание через него не проходит.
- Удалить беседу полностью: правый клик по беседе в списке → «Удалить».

## Частые проблемы

| Проблема | Решение |
|---|---|
| Микрофон/камера не работают | Откройте приложение по HTTPS (или localhost на ПК) и разрешите доступ в настройках сайта |
| Соединение не устанавливается | Убедитесь, что оба устройства онлайн; попробуйте из одной Wi-Fi-сети; создайте приглашение заново |
| Код «не подходит» | Код нужно передать целиком, включая префикс `FCHAT-O-`/`FCHAT-A-`; ответный код действует только для своего приглашения |
| «Локальное хранилище переполнено» | Удалите старые беседы с файлами (правый клик по беседе) |
| Приложение не ставится на телефон | Проверьте, что открыли именно HTTPS-ссылку (не `http://`), и что в Chrome есть пункт «Установить» |
